# 🚀 Encurtador de URLs  

Um encurtador de URLs simples feito com **Spring Boot**, **Spring Data JPA**

## 📌 Tecnologias Utilizadas  
- **Java 17**  
- **Spring Boot 3.4.2**  
- **Spring Web**  
- **Spring Data JPA**    
- **Lombok**  
- **Railway (para deploy)**  



## 🔥 Melhorias Futuras  
✅ Melhorar o sistema de geração de URLs curtas  
⬜ **Autenticação de usuários** — Permitir que usuários se registrem e gerenciem suas próprias URLs encurtadas com login via JWT  
⬜ **Dashboard de estatísticas** — Painel com métricas de acesso por URL: total de cliques, cliques por dia/mês, dispositivo e localização geográfica  
⬜ **URLs personalizadas** — Permitir ao usuário definir um alias customizado para a URL curta (ex: `dominio.com/meu-link`)  
⬜ **Expiração de URLs** — Suporte a URLs com data de expiração configurável, desativando automaticamente o redirecionamento após o prazo  
⬜ **QR Code automático** — Geração automática de QR Code para cada URL encurtada  
⬜ **Rate limiting** — Limitação de requisições por IP para evitar abusos e ataques de força bruta  
⬜ **Painel administrativo** — Interface para gerenciamento completo das URLs cadastradas (listar, ativar/desativar, excluir)  
⬜ **Documentação da API** — Integração com **SpringDoc OpenAPI (Swagger UI)** para documentação interativa dos endpoints
